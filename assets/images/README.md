# Bilder für die MS Media Website

Die Website funktioniert auch ohne Fotos (elegante Gradient-Platzhalter werden
angezeigt). Sobald du hier Bilder ablegst, werden sie automatisch geladen.

Lege einfach folgende Dateien von deiner alten Homepage
(www.michaelstabentheiner.at) in diesen Ordner:

| Dateiname                   | Verwendung                              | Empfehlung        |
|-----------------------------|------------------------------------------|-------------------|
| `pictures-in-motion.jpg`    | Großes Showcase-Bild „Pictures in Motion" | 1920×1080 (16:9)  |
| `tourismus.jpg`             | Portfolio-Karte „Tourismus & Regionen"   | 1200×750 (16:10)  |
| `imagefilm.jpg`             | Portfolio-Karte „Imagefilme & Werbespots"| 1200×750 (16:10)  |
| `drohne.jpg`                | Portfolio-Karte „Luftaufnahmen"          | 1200×750 (16:10)  |
| `michael-stabentheiner.jpg` | Porträtfoto im Bereich „Über uns"        | 1000×1250 (4:5)   |

Tipps:
- JPG mit ~80 % Qualität reicht, gerne als WebP zusätzlich.
- Bilder vor dem Upload auf die empfohlene Größe verkleinern (Ladezeit!).
