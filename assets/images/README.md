# Bilder & Video für die Website

Aktuell verwendet die Seite Standbilder aus dem hochgeladenen Showreel-Video.
Du kannst sie jederzeit durch eigene Fotos ersetzen — einfach Datei mit
gleichem Namen überschreiben:

| Dateiname                   | Verwendung                                  |
|-----------------------------|----------------------------------------------|
| `hero-poster.jpg`           | Vorschaubild des Hero-Videos (Header)        |
| `showreel-poster.jpg`       | Vorschaubild des Showreel-Players (Arbeiten) |
| `tourismus.jpg`             | Portfolio-Karte „Tourismus & Regionen"       |
| `pictures-in-motion.jpg`    | Portfolio-Karte „Pictures in Motion" (fehlt noch — Gold-Platzhalter aktiv) |
| `drohne.jpg`                | Portfolio-Karte „Luftaufnahmen" (fehlt noch — Gold-Platzhalter aktiv) |
| `michael-stabentheiner.jpg` | Porträtfoto „Über uns" (fehlt noch — Gold-Platzhalter aktiv), ideal 1000×1250 (4:5) |

Video: `assets/video/showreel-web.mp4` (weboptimiert, ohne Ton) läuft als
Hero-Hintergrund und im Showreel-Player. Das Original liegt als
`showreel.mp4` daneben. Neues Video? Beide Dateien ersetzen — die
Web-Version idealerweise ohne Tonspur und mit H.264/CRF ~25 komprimieren.
